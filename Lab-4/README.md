This folder contains the completed Lab-4 work for the Match-3 Gem Swap Repair Lab.

1. **Invalid swap move deduction bug fixed**

   Consecutive gravity-triggered reaction chains receive increasing score multipliers within a single turn.

3. **Four-in-a-row special line-clear gems**  
   Matching four gems creates an enhanced special gem that clears its row or column when activated.

4. **Idle hint indicator**  
   After more than 5 seconds without input, an available adjacent swap pair is highlighted with a pulsing hint.
